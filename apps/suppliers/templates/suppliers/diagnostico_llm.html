{% extends "base_operativo.html" %} {% comment %} Diagnóstico del modelo de lenguaje. No es de ningún caso de uso: es una herramienta de operación. El pipeline de CU-04 depende de un servicio que corre afuera de Django y que se apaga sin avisar, y sin esta pantalla la única forma de descubrirlo es que un correo quede fallido con un mensaje genérico. Modo operativo, con una licencia deliberada: el indicador de estado de arriba es más grande de lo que pide una pantalla densa. Se justifica porque es **el único dato que se viene a mirar** — quien abre esta pantalla tiene una pregunta sí/no y tiene que responderla sin leer. Los tres acentos se usan con su significado del sistema visual: `signal` para lo que hay que atender (servicio caído, reparos), `azure` para lo que derivó el sistema (latencias, valores interpretados), `static` para el resto. {% endcomment %} {% block titulo %}Diagnóstico del modelo · Longbox{% endblock %} {% block seccion %}Proveedores{% endblock %} {% block cabecera_extra %} {{ block.super }} {% endblock %} {% block contenido %}
