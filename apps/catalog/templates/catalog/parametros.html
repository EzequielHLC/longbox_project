{% extends "base_operativo.html" %} {% load l10n %} {% comment %} Parámetros globales: lo que el negocio ajusta sin tocar código. Están todos en una pantalla porque se consultan juntos. Para entender por qué un tomo salió a un precio hay que ver cuatro cosas —la tabla, el tipo, el formato y el margen— y tenerlas en cuatro pantallas distintas obliga a ir y volver perdiendo el hilo. Las etiquetas no entran en el precio, pero son el eje descriptivo del catálogo y se administran igual que el resto. El alta y la edición de cada cosa van aparte y no en línea: cada una tiene sus propias validaciones, y resolverlas todas en un mismo formulario haría que un error en el margen borrara lo que se estaba escribiendo en la tabla de precios. {% endcomment %} {% block titulo %}Parámetros globales · Longbox{% endblock %} {% block seccion %}Parámetros{% endblock %} {% block cabecera_extra %} {{ block.super }} {% endblock %} {% block contenido %}
