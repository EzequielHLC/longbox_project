{% comment %} Autocompletado propio sobre un ``. Se conserva por una razón que no es de dibujo: la lista nativa busca distinguiendo acentos, y nadie escribe «Oberá» con tilde mientras busca. Acá el `` sigue siendo la *fuente de datos*; al campo se le saca el atributo `list` para que el navegador no muestre la suya encima de ésta. Sin JavaScript el atributo `list` sigue puesto y el navegador hace lo suyo: se degrada al comportamiento nativo, que es feo pero funciona. Se aplica a los campos con `data-autocompletado=""`. {% endcomment %}
